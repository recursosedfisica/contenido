# Recursos Abiertos de Educación Física

Biblioteca estática de recursos educativos interactivos elaborados con eXeLearning.

**Autores del portal:** Diego González Buchacski y Santiago Izaguirre Montes.

## Publicación en GitHub Pages

El sitio no necesita instalación ni proceso de compilación. Debe publicarse desde la raíz del repositorio. El archivo principal es `index.html` y cada recurso se encuentra dentro de `recursos/`.

La presencia de `.nojekyll` evita que GitHub Pages procese las carpetas y archivos internos de eXeLearning con Jekyll.

## Estructura

- `index.html`: portada y catálogo.
- `assets/`: estilos, lógica de filtrado y logos.
- `recursos/`: exportaciones autocontenidas de eXeLearning.

Cada recurso conserva su autoría, créditos y licencia original en sus propias páginas.
